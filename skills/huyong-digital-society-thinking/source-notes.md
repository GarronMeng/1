# Source Notes

This skill is an interpretive framework inspired by public discussions around digital society, internet culture, platform power, public discourse, and human subjectivity.

It is designed as a thinking aid, not as a database of direct quotations.

## Recommended wording

Use cautious wording such as:

- “胡泳式视角”
- “受胡泳数字社会问题意识启发”
- “可以借用这一数字社会分析框架理解”
- “这不是直接引文，而是观点蒸馏”

## Attribution discipline

When academic, journalistic, or formal accuracy matters, separate the following layers:

1. direct quotation;
2. paraphrase;
3. interpretation;
4. extension;
5. application to a new case.

## Recommended workflow

When using this skill for formal writing:

1. Start with the analytical framework in `SKILL.md`.
2. Identify the specific topic to analyze.
3. Search for relevant original texts, interviews, books, or public lectures.
4. Mark which claims are directly sourced and which are interpretive extensions.
5. Do not present interpretive summaries as exact quotations.

## Purpose

The purpose of this repository is to create a reusable thinking tool for AI-assisted analysis.

The safest formulation is:

> This analysis is inspired by a digital society perspective. It is not a direct quote unless a specific source is provided.
