# Hu Yong Digital Society Thinking Skill

A lightweight AI skill for analyzing digital society, AI, platforms, public discourse, and human subjectivity through a Hu Yong-inspired framework.

## What this is

This repository distills a mode of thinking inspired by Chinese scholar Hu Yong's public work on the internet, digital society, public discussion, media change, and technology's impact on human subjectivity.

It is not a quote database.

It is a reusable analytical framework for AI assistants, writers, researchers, strategists, students, and public-interest practitioners.

## Core idea

Technology should not be analyzed only as a tool.

It should be analyzed as a force that reorganizes:

- relationships;
- power;
- attention;
- public discussion;
- institutional arrangements;
- human subjectivity.

A concise formulation:

> Digital technology is not merely a tool. It is an environment, infrastructure, and institutional arrangement that reshapes human life.

## When to use this skill

Use this skill when analyzing:

- AI and human agency
- digital transformation
- platform power
- social media
- algorithms
- misinformation and post-truth
- public discourse
- digital civilization
- internet culture
- technology ethics
- media change

```text

```

## Important note

This skill is an interpretive framework inspired by Hu Yong's public intellectual concerns. It does not claim to reproduce his exact words. When academic precision is required, users should consult original texts and cite specific sources.
